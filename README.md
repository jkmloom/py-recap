# Python, Revisited 🐍

> A structured journey through Python — from the fundamentals to more advanced concepts.

I created this repository to get back to the foundations of programming and computer science, build a stronger understanding of the tools I use, and make those learning notes useful to others along the way.

---

## Why This Repository Exists

For a while, I found myself going off track. I was distracted and dealing with a difficult period, and when I started feeling better, I noticed that I had become too dependent on AI-assisted coding — often called *prompt coding* or *vibe coding*.

AI is a powerful tool. It can help us explore ideas, improve code, optimize solutions, and build projects faster. But using it should not mean giving up our understanding of what we build.

The important part is not just getting code that works. **We should understand the code, regardless of who or what wrote it.** AI can support the learning and development process, but it should not become our only source of understanding or something we rely on blindly.

So I decided to rewind: revisit the basics, strengthen my programming fundamentals, and work back through core computer science concepts.

## Why Python?

Python is a great language for revising programming fundamentals and building conceptual clarity. Its readable syntax lets me focus on the ideas behind the code instead of getting caught up in unnecessary complexity.

This repository is my attempt to create a clear, detailed, and organized path through Python — starting with the basics and gradually moving toward more advanced topics.

## A Note on Learning With AI

I don't think AI should be avoided. It can be an excellent assistant for learning, debugging, reviewing, optimizing, and building software.

The distinction is between **using AI as a tool** and **depending on it without understanding the result**.

When using AI to help with code, try to understand:

1. What the code does.
2. Why the approach works.
3. What assumptions it makes.
4. Where it might fail.
5. Whether you could explain or modify it yourself.

The aim is not to reject better tools. It is to build the knowledge needed to use them well.

## How to Use This Repository

1. Start with the fundamentals if you are new to Python or need a refresher.
2. Read each explanation at your own pace.
3. Run the examples instead of only reading them.
4. Change the code and observe what happens.
5. Write small programs from memory to test your understanding.
6. Return to earlier topics whenever a later concept depends on them.

**Reading is a start; writing and experimenting with code is where understanding grows.**
